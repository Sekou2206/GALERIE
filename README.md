# Galerie Clevart

Décompressez cette archive puis déposez TOUS ses fichiers à la racine de votre dépôt GitHub, sans sous-dossier. Activez GitHub Pages depuis la branche souhaitée et le dossier / (root).

Le site doit être servi en HTTP(S) : ouvrir index.html directement comme fichier local ne charge pas les modules 3D.

8 tableaux intégrés, cadrages et couleurs conservés. Les titres des trois nouveaux tableaux sont descriptifs, à confirmer par l’artiste.

La playlist PLIqSPDbNIT2I est fixée dans music.js. Aucun champ de modification n’est proposé aux visiteurs. Appuyez sur Musique puis Lire : les restrictions des navigateurs empêchent de garantir un démarrage sonore automatique. Le disque tourne pendant la lecture. Fermer le lecteur met en pause.

YouTube nécessite une connexion et des vidéos autorisées à être intégrées. La lecture réelle de la playlist n’a pas pu être vérifiée ici.
