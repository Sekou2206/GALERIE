# Clevart — Galerie immersive

Tous les fichiers sont à la racine, sans sous-dossier.

## Mettre le site en ligne

1. Décompressez ce ZIP sur votre ordinateur.
2. Envoyez tous les fichiers extraits à la racine de votre dépôt GitHub (pas le ZIP).
3. Activez GitHub Pages pour la branche contenant les fichiers, dossier racine.

Le site est statique : aucune compilation ni installation nécessaire.
Pour le tester sur votre ordinateur, utilisez un serveur local, par exemple Live Server dans VS Code. L’ouverture directe de index.html par double-clic ne permet pas toujours de charger les modules JavaScript.

Conservez exactement ces noms, en minuscules. Les intitulés affichés dans la galerie sont descriptifs et peuvent être modifiés dans app.js avec les informations des œuvres. Les photos fournies sont incluses.

## Fichiers

- index.html : structure et textes des fiches
- style.css : présentation et adaptation mobile
- app.js : galerie 3D, tableaux et navigation
- three.module.js : moteur 3D, à conserver avec les autres fichiers

## Commandes

Glisser : regarder. Clic au sol : se déplacer. ZQSD / WASD / flèches : marcher. Cliquer sur un tableau : s’approcher, puis ouvrir sa fiche. Le plan et la visite guidée permettent de parcourir les cinq œuvres.

Le ZIP ne contient aucune restriction d’accès : la visibilité du site dépend de votre hébergement.
